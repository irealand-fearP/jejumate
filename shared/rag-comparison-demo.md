# RAG + 신뢰도 검증 비교 데모

같은 질문 4개를 (A) gpt-5-mini 단독 호출과 (B) gpt-5-mini + RAG + 신뢰도 검증
파이프라인에 각각 실제로 넣어 뽑은 결과다. 조작 없이 실제 API 응답을 그대로 기록했다
(호출 시각: 2026-07-08, 로컬 개발 DB 기준).

각 질문의 (B) 결과는 실제 서비스 코드 `answer_rag_question()`이 반환한 값이고,
(A)는 같은 모델(`gpt-5-mini`, `reasoning_effort=minimal`)에 근거 문서 없이 질문만
그대로 보낸 결과다 — 모델 성능 차이가 아니라 **RAG 근거 + 검증 유무**만 다르다는 것을
보여주기 위함.

---

## 질문 1. "함덕 점심 추천해줘"

**A. gpt-5-mini 단독 (근거 없음)**
> 함덕(제주)에서 점심 먹기 좋은 곳 추천해달라는 말씀이시죠? ... 1) 해산물/회 - 함덕
> 서우봉 근처 횟집들: 신선한 회와 성게미역국, 전복 등 해산물 요리 가능. (예: 현지
> 횟집들 - 점심 메뉴는 매장별로 확인 필요) ... 원하시면 ... 알려주세요. 그러면
> 위치와 영업시간·대표메뉴까지 자세히 알려드릴게요.

- 구체적인 식당명("서우봉 근처 횟집들" 등)을 나열하지만, 실제로 존재/검증된 정보인지
  근거가 없다 — 전형적인 **환각(hallucination) 위험**. 되묻는 질문으로 답을 회피하기도 함.
- 토큰: prompt 13 / completion 444 / total **457**

**B. gpt-5-mini + RAG + 검증**
> 함덕 해수욕장 근처 점심은 혼밥보다 2~4명 정도의 밥친구와 함께 예약하면 대기 시간이
> 짧고, 식사 후 해변 산책으로 이어가기 좋습니다.

- 신뢰도: **medium (근거 2건 중 1건 일치)** — 큐레이션 문서(제주메이트 검증 데이터)는
  일치, 카카오톡 수집 문서 1건은 답변과 무관해 불일치로 스스로 걸러냄.

## 질문 2. "비 오는 날 코스 알려줘"

**A. gpt-5-mini 단독 (근거 없음)**
> 비 오는 날에 어울리는 코스(데이트/나들이/실내외 활동 등) 원하시는 방향이
> 있으신가요? ... 원하시는 지역(예: 서울 강남, 부산, 경기 등)과 출발 시간이나 예산을
> 알려주시면 날씨에 맞춘 구체적 코스를 추천해 드릴게요.

- 제주라는 맥락 자체를 모른다(서울/부산을 되물음) — 커뮤니티 특화 정보가 전혀 없다.
- 토큰: prompt 13 / completion 167 / total **180**

**B. gpt-5-mini + RAG + 검증**
> 비 오는 날에는 오션뷰 카페에서 작업을 하고, 실내 전시를 관람한 뒤 공유오피스
> 네트워킹에 참여하는 코스가 만족도가 높습니다. 이동팟을 함께 잡으면 비용 부담을
> 줄일 수 있습니다.

- 신뢰도: **high (근거 1건 중 1건 일치)** — 제주메이트 큐레이션 데이터와 완전히 부합.

## 질문 3. "제주공항 택시팟 있나요?" — 검증 기능의 핵심 사례

**A. gpt-5-mini 단독 (근거 없음)**
> 네, 제주공항에도 택시팟(택시 합승 대기 서비스)이 있습니다. ... 위치: 제주공항
> 도착층(1층) 택시 승차장 근처에 택시 대기구역과 합승 탑승 안내가 있는 경우가
> 많습니다. ... 호출 앱: 카카오T, 티맵택시 등 주요 택시 호출 앱에서 공항 택시 호출
> 및 합승 옵션을 확인해 보세요. ...

- **자신 있게 "네, 있습니다"로 단정하며 존재하지 않는 공식 서비스("공항 택시 합승
  대기구역", "호출 앱 합승 옵션")를 그럴듯하게 지어냄.** 실제로 제주메이트의
  택시팟은 공식 서비스가 아니라 학생들이 오픈채팅방에서 자체적으로 모집하는 것이라,
  이 답변은 사실과 다르다 — RAG 없는 LLM의 전형적 환각 사례.
- 토큰: prompt 18 / completion 369 / total **387**

**B. gpt-5-mini + RAG + 검증**
> 제공된 정보로는 답변하기 어렵습니다

- 신뢰도: **low (근거 3건 중 0건 일치)** — 코사인 유사도 threshold(0.5)는 통과한
  카카오톡 수집 문서 3건이 검색됐지만, 검증 단계에서 "이 문서들이 실제로 이 질문에
  대한 답을 뒷받침하지 않는다"고 스스로 판단해 **추측 답변을 만들지 않고 정직하게
  모른다고 응답**했다. 근거는 있었지만 근거-답변 일치도가 0이라는 걸 점수로 노출한
  것 — 검증 단계가 없었다면 (A)처럼 근거 없이도 그럴듯한 답을 만들어냈을 위험이 크다.

## 질문 4. "제주도 여행 준비물 뭐가 있어?" — 근거 없음(비용 절약 경로)

**A. gpt-5-mini 단독 (근거 없음)**
> 제주도 여행 준비물은 계절·여행 스타일(자유여행 vs 패키지), 활동(등산·해수욕·카약
> 등)에 따라 달라지지만... (8개 항목, 800자 이상의 일반적인 여행 준비물 목록)

- 일반 상식 수준의 답은 그럴듯하지만, 제주메이트 커뮤니티 고유 정보(신뢰할 근거)는
  전혀 아니다.
- 토큰: prompt 16 / completion 828 / total **844**

**B. gpt-5-mini + RAG + 검증**
> 지금 조건에 맞는 유효한 정보를 찾지 못했어요. 다른 질문으로 다시 시도해주세요.

- 신뢰도: **none** — 코사인 유사도 threshold(0.5)를 넘는 근거 문서가 하나도 없어서
  **LLM을 아예 호출하지 않았다**(비용 0). 근거 없이 자신 있게 답하는 대신 정직하게
  "모른다"고 응답.

---

## 요약

| 질문 | 단독 답변 성격 | RAG+검증 신뢰도 | RAG+검증 LLM 호출 |
|---|---|---|---|
| 함덕 점심 추천 | 근거 없는 일반 지식(환각 위험) | medium (1/2) | 호출함 |
| 비 오는 날 코스 | 제주 맥락조차 모름 | high (1/1) | 호출함 |
| 제주공항 택시팟 | **확신에 찬 허위 정보 생성** | low (0/3) → 정직하게 회피 | 호출함(검증에서 거름) |
| 여행 준비물 | 일반 상식 나열 | none → 근거 없음 응답 | **호출 안 함(비용 절약)** |

**차별점**: 단독 LLM은 근거가 없어도 항상 그럴듯한 답을 만들어내지만(질문 3이 가장
위험한 사례), RAG+검증 파이프라인은 "근거가 실제로 답변을 뒷받침하는지"까지 확인해
근거가 부족하면 점수로 드러내고 정직하게 답을 거절한다. 근거가 아예 없으면 LLM
호출조차 하지 않아 비용도 아낀다.
