# 시냅스팟(SYNAPSE POT) 배경지식 브리핑
> 발표 대본·자료 작성용 컨텍스트 문서. 2026-07-16 기준 사실만 담음.

## 1. 한 줄 소개
**시냅스팟** — 제주대학교 계절학기·런케이션 학생들을 위한 **실시간 커뮤니티 기반 로컬 서비스**. 카카오톡 오픈채팅에 흩어진 동행·이동·생활 정보를 모아, **근거 있는 AI 답변**과 **파티(모임) 매칭**으로 연결한다.

- 서비스 URL: https://snp.rtvoice.com
- 이름 유래: 시냅스(연결) + 팟(모임/pot). 로고 = 손 두 개가 시냅스로 연결되는 일러스트
- 이전 이름: 제주메이트(7/9 리브랜딩). 코드·저장소명은 jejumate 유지
- 대상: 2026 하계 계절학기 제주대 학점교류 학생(오픈채팅방 1,164명)

## 2. 해결하는 문제
1. 계절학기 학생은 제주에 연고가 없다 — 택시팟·밥친구·생활정보를 **1,164명 오픈채팅 스크롤**로 찾아야 함
2. 일반 챗봇(GPT)은 "지금 제주"를 모른다 — 그럴듯한 일반론만 말함(환각 위험)
3. 익명성과 신뢰의 균형 — 실명 없이 가볍게, 그러나 노쇼·안전 문제 방지 필요

## 3. 핵심 기능 (전부 라이브 작동)
- **파티(모임)**: 등록(4자리 관리코드) → 신청 → 호스트 승인/거절 → 승인자 전용 채팅. 탈퇴/해산, 정원·인기·NEW 배지, 마감 후 자동 정리(마감+2일 삭제)
- **질문(AI 챗봇)**: LLM 대화형 UI(내 질문 오른쪽, 답변 왼쪽). RAG로 커뮤니티·공식 근거 검색해 답변, 근거 배지·출처 표시, 근거 없으면 "커뮤니티 근거 없음" 표시 후 일반지식 답변
- **생활게시판**: 질문게시판/중고거래·나눔/꿀팁/기타. 글쓰기·댓글·신고. 오픈채팅에서 수집한 글 자동 분류 유입("오픈채팅에서 온 글" 배지)
- **지도**: 팀원 제작 캠퍼스맵 — 2D(카카오맵)/3D(브이월드) 토글, 건물 검색, 셔틀버스 실시간 노선·운행 정보
- **홈**: 오늘 열린 파티 타임라인, 퀵매치, 실시간 참여자 수, ＋버튼(파티 생성/글쓰기)
- 익명 정책: 닉네임만으로 사용(비로그인), 신청 시에만 확인

## 4. 데이터 파이프라인 (차별점 1)
**카카오톡 오픈채팅 → 자동 수집 → RAG 근거화**
- Windows에서 카카오톡 대화 내보내기를 **완전 자동화**(창 제어 Ctrl+S, 30분 주기, 무인)
- 10분 주기 업로드 → 개인정보 마스킹(전화·인스타 등)·노이즈 필터(ㅋㅋ 등 제거) → 임베딩 → 분류
- 수집 글은 용도별로 흐름: 동행 모집 → 카톡 파티(4시간 후 자동삭제), 질문/중고/꿀팁 → 게시판, 전체 → RAG 근거
- 현재 규모: **카톡 근거 약 10,600건**, 게시판 1,600여 글, 제주대 공식 문서·캠퍼스맵 색인 포함

## 5. RAG 구조 (차별점 2)
- 모델: **gpt-5.5** (답변+신뢰도 자기검증 1회 호출), 임베딩 text-embedding-3-small
- 검색: **pgvector**(Supabase PostgreSQL) 최근접 3건, 유사도 임계값 0.5 — **미달 시 임의 문서 반환 금지**
- **출처 라우팅**: 장학금·휴학·셔틀 같은 공식 질문 → 제주대 공식 문서·통합검색·캠퍼스맵 / 생활·동행 → 커뮤니티 근거
- **정직한 폴백**: 근거 없으면 지어내지 않고 일반지식 답변 + "커뮤니티 근거 없음" 배지(`answer_source` 필드)
- 답변에 근거 신뢰도 배지(근거가 잘 맞아요/일부/약해요) + 출처 카드 + 위치 질문엔 지도 미니맵

## 6. RAG 개선 여정 (발표 서사 — 7단계)
1. **출발(7/7)**: 키워드 LIKE + "매칭 없으면 아무 문서나 반환" = 사실상 가짜 RAG
2. **진짜 검색(7/7)**: 임베딩+코사인+임계값 0.5, "근거 없으면 없다고" 원칙
3. **데이터(7/8)**: 시드 45건 → 카톡 실시간 수집 파이프라인 구축
4. **속도(7/8)**: 문서 증가로 9~18초 → pgvector로 2.4~4.4초
5. **정직함(7/9)**: 과잉 회피 프롬프트 버그 수정 + 일반지식 폴백/배지 도입
6. **측정이 방향을 바꿈(7/15)**: RAGAS 정량평가 → "무관한 커뮤니티 글 검색 시 −21.6%" 발견 → **출처 라우팅** 도입
7. **재검증(7/15)**: Faithfulness **0.345 → 0.806(2.3배)**, 근거 활용도 0.571→0.875

## 7. 평가 수치 (RAGAS 0.4.3, 15문항)
| 지표 | 개선 전 | 개선 후 |
|---|---|---|
| Faithfulness(근거 부합/환각 억제) | 0.345 | **0.806** |
| 검색 근거 활용도 | 0.571 | **0.875** |
| 출처 제시율 | 0.467 | 0.533 |
| RAG 답변 관련성 | 0.637 | 0.507* |

*관련성 하락은 "근거 없으면 지어내는 대신 정직하게 공식 출처 안내"를 택한 **의도된 트레이드오프**. 신뢰 중심 서비스로서 바람직한 방향이라고 설명할 것.
- 대표 사례: ①장학금 질문 — 공식 근거로 구체 답변(win) ②보건소 질문 — "근거 없음, 공식 확인 권장" 정직 회피(관련성 0점이지만 환각 0) ③"시청 택시팟 자주 올라와?" — 일반 GPT는 "잘 안 올라온다" 오답, RAG는 실데이터로 "자주 올라온다" 정답
- 별도 정성 비교(캐주얼 질문 15개): 실데이터 질문 8/8 RAG 우위, 환각 0건

## 8. 기술 스택·아키텍처
- **프론트**: Next.js(App Router, TypeScript) — 모바일 우선. 자체서버 + Vercel 백업 배포
- **백엔드**: FastAPI(Python) — 자체서버 상시 프로세스(콜드스타트 없음, 응답 0.06~0.1초)
- **DB**: Supabase PostgreSQL(서울 리전) + pgvector
- **수집기**: Windows 예약작업 + PowerShell/Python (카톡 자동 내보내기·업로드)
- **배포**: 자체서버(메인, snp.rtvoice.com) + Vercel(백업). GitHub Actions 크론(수집 트리거)
- **AI**: gpt-5.5(답변), text-embedding-3-small(임베딩), RAGAS(평가)
