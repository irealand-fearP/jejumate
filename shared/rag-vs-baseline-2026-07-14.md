# 시냅스팟 RAG vs gpt-5-mini 단독 — 발표용 검증 리포트

> **발표용 웹 페이지(조원 공유용)**: https://claude.ai/code/artifact/00cf466d-325e-4a22-85d7-8146225e5f5f
> (기본은 비공개. 상단 공유 메뉴에서 팀원에게 공개 가능. 같은 폴더 `rag-vs-baseline-2026-07-14.html`은 오프라인 열람용.)

**측정일** 2026-07-14 · **모델** gpt-5-mini(양쪽 동일) · **질문** 15개 × 2방식 · **실행** 라이브 API

## 방법
같은 모델·같은 질문을 두 방식으로 실행해 유일한 변수를 "우리 데이터를 봤느냐"로 고정.
- **단독**: 검색 없이 gpt-5-mini 일반 지식만 (`generate_general_answer`)
- **RAG**: 카톡 오픈채팅·학교 데이터에서 근거 검색 후 답변 (`/api/rag/ask`)
- 근거 코퍼스: 카카오톡 5,521 · 생활게시판 135 · 파티 26
- RAG 응답의 `answer_source`: `community`(근거 확보) / `general_knowledge`(근거 부족→일반지식 전환)

## 요약 스코어
| 지표 | 값 |
|---|---|
| RAG가 실제 근거 확보(community) | **12 / 15** |
| 실데이터 질문에서 RAG 구체성 우위 | **8 / 8** |
| 근거 없을 때 지어낸 답(환각) | **0건** (모르면 "모른다") |
| 일반 상식이라 단독도 충분 | 3 / 15 (정직한 대조군) |

## 핵심 사례
- **Q05 어바웃커피 와이파이** — 둘 다 "모른다"지만 RAG는 *근거에 문의글만 있고 비번은 없다*고 밝힘 → **환각 없이 정직**.
- **Q08 시청 택시팟** — 결론이 정반대. 단독 "잘 안 올라온다"(추측) vs RAG "자주 올라온다"(근거 확인).
- **Q03 공항 택시 시간** — RAG는 실제 글에서 **"오전 10시"** 구체 시각 추출, 단독은 비행기 시간 기준 일반론.
- **Q10 1호관 세탁실** — RAG "B동 세탁기 90분 사용 중" 실시간 vs 단독 운영시간 추정.
- **Q14 흑돼지(정직한 한계)** — 일반 상식은 오히려 단독이 나음. RAG는 근거 없으면 설명 회피.

## 결론
1. **구체성** — 실데이터 질문 8/8 RAG 우위(실제 글·시각·장소 인용).
2. **신뢰성** — 근거 없으면 "근거 없음" 명시, 지어내지 않음.
3. **오류 교정** — 단독의 그럴듯한 오답(Q08)을 데이터로 바로잡음.
4. **정직한 한계** — 일반 상식은 단독이 충분/우위 → 시냅스팟은 근거 있으면 RAG, 없으면 일반지식으로 **자동 전환하는 하이브리드**로 설계됨.

*원자료(질문별 전체 답변)는 검증 실행 로그에 있음. 재현: `services/api`에서 15문항을 `/api/rag/ask` + `generate_general_answer`로 각각 호출.*
